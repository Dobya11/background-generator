# Background generator

Repository for a tool that creates backgrounds for PCs, browsers, etc.

Uses assets created by [Kenney](https://kenney.nl/) - [Pattern Pack](https://kenney.nl/assets/pattern-pack) and [Pattern Pack Extra](https://kenney.nl/assets/pattern-pack-extra).
